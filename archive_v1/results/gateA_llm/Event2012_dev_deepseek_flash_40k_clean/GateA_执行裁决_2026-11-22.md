## 三、诚实归因与论文主张校准（关键科学结论）

1. **核心问题（“有限次真实开源 LLM 判断能否大幅改善未查询帖的全局划分”）明确 PASS**：
   * 在同等 ~40,000 真实 Token 预算（仅占整块 ~0.86% 帖子、总开销 < 0.10 元）下，`random` / `rep_div` / `cequel_edge` 均停留在 `-0.05 ~ +0.01 pp`（几乎零改善，甚至因真实 LLM 误判略微掉点）；
   * `SUG-Router` 在全部 4 个开发块上无一掉点，均值实现 **`+3.36 pp` AMI、`+2.45 pp` 事件宏 $B^3$、`+6.23 pp` 未查询帖微 $B^3$、`+2.12 pp` 未查询帖宏 $B^3$**，每块净改善 **518–537 条未查询帖子**、净消除 **27,094 对误拆分**。
2. **明确剥离两层收益来源（避免夸大“拓扑修边”贡献）**：
   * **第一大收益源（约占 85%–90%）来自“介观结构缝隙查询（Mesoscopic Seam Querying）”**：用对称的簇对合并缝隙（`MERGE_PAIR`）+ 偏态少数口袋切分缝隙（`SPLIT_SEAM`）取代单帖/单边查询，使单次 LLM 判决直接作用于整块事件结构；
   * **第二层稳定增量（约占 10%–15%，`+0.35 pp` 宏 $B^3$、`-75` 误合并）来自 Branch 2 约束重聚类**：在 `Event2012` 上，对切分出的子簇与孤立种子执行图边修复 + 热启动 2D SE 重聚类，在 3/3 有效块上稳定跑赢同判决直接编辑；
   * **重要边界发现（来自法语 `Event2018` 预检）**：当单个大事件占全块 40% 体积时，无约束的 `refine_2d_se_node_moves` 会因大簇体积 $V_{12}$ 膨胀产生的“体积排斥”反向挤出已合并节点。因此下一步正式方法设计中必须将节点移动精修**锁定在切分/边界邻域，禁止反向瓦解已确认 `MERGE` 核心**。
